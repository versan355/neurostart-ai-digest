# НЕЙРОСТАРТ — AI-дайджест для новичков

Одностраничный сайт на Flask: десять карточек с материалами об ИИ,
фильтры по типу, плавные анимации и форма подписки.
Всё работает локально, без базы данных и внешних сервисов.

## Запуск

Откройте PowerShell **в папке проекта** и выполните:

```powershell
cd C:\Users\T\Documents\Site
pip install -r requirements.txt
python app.py
```

Затем откройте <http://127.0.0.1:5050>.

> Порт 5050 указан в конце `app.py`. Если он занят, поменяйте число
> на любое свободное, например 8000, и откройте тот же адрес с новым портом.

Можно проще: двойной щелчок по **`start.bat`** — он сам перейдёт в нужную
папку и запустит сервер. Окно закрывать нельзя, пока пользуетесь сайтом.

### Если PowerShell пишет «can't open file app.py»

Значит команда выполнена не в папке проекта (например, в `C:\`).
Сначала перейдите в неё:

```powershell
cd C:\Users\T\Documents\Site
python app.py
```

Проверить, где вы находитесь, можно командой `pwd`. В конце пути должно
быть `\Site`.

> Если `flask` не установлен, достаточно одной команды: `pip install flask`.

## Структура проекта

```
Site/
├── app.py                  # данные карточек + маршруты Flask
├── requirements.txt
├── subscribers.txt         # появится после первой подписки (демо)
├── templates/
│   └── index.html          # HTML-шаблон страницы
└── static/
    ├── css/style.css       # все стили
    └── js/main.js          # фильтры, анимации, прогресс чтения
```

## Как добавить карточку

Откройте `app.py`, найдите список `MATERIALS` и скопируйте любой словарь.
Поменяйте поля:

```python
{
    "title": "Название материала",
    "description": "Пара предложений: зачем это новичку.",
    "url": "https://example.com/material",
    "category": "guides",          # tools | guides | courses
    "category_title": "Гайд",      # подпись на карточке
    "duration": "10 минут",
    "level": "Новичок",
    "tags": ["промпты", "практика"],
    "accent": "cyan",              # lime | violet | cyan | pink
}
```

Количество в фильтрах и счётчик пересчитаются сами.

## Как поменять внешний вид

Почти всё настраивается в начале `static/css/style.css`:

- `--bg` — цвет фона;
- `--lime`, `--violet`, `--pink`, `--cyan` — акценты;
- `--radius` — скругление карточек;
- `--container` — максимальная ширина страницы.

Шрифты подключены в `templates/index.html` через Google Fonts
(Unbounded для заголовков, Manrope для текста). Без интернета
сайт останется рабочим — сработают системные шрифты.

## Форма подписки

Это демонстрация: адрес проверяется и дописывается в `subscribers.txt`
рядом с `app.py`. Письма никуда не отправляются, данные не передаются.
Для настоящей рассылки понадобится почтовый сервис и ключ API.

## Что стоит знать

- `debug=True` в `app.py` удобен при разработке, но его нужно выключить
  перед публикацией сайта.
- Секретный ключ `app.secret_key` в учебном проекте условный.
  Для настоящего сайта его берут из переменной окружения.
- Внешние ссылки открываются в новой вкладке (`target="_blank"`).
